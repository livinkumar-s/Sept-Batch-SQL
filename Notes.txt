Joins 
--------
>> It is used to combine rows from two or more tables based on related columns.

Inner Join 
--------------
>> It Retrives matching rows from both tables.
>> It skips the unmatched rows.
Ex: SELECT * FROM tb1 INNER JOIN tb2 ON relation;

Left Outer Join 
----------------
>> It retrives all records from left table.
>> only matching record from right table.
Ex: SELECT * FROM tb1 LEFT JOIN tb2 ON relation;

Right Outer Join 
----------------
>> It retrives all records from right table.
>> only matching record from left table.
Ex: SELECT * FROM tb1 RIGHT JOIN tb2 ON relation;

Full Outer Join 
----------------
>> It retrives all records from both table.
Ex: SELECT * FROM tb1 RIGHT JOIN tb2 ON relation
UNION 
SELECT * FROM tb1 LEFT JOIN tb2 ON relation;
