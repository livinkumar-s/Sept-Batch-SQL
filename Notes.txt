Database 
-----------
>> It is organized collection of data that can be accessed and modified easily.

RDBMS --> Relational Database Management System 
--------------------------------------------------
>> Data is stored in form of Tables (Rows and Columns)
>> SQL is needed.
>> Ex: MySQL, PostreSQL, Oracle....

DBMS --> NoSQL 
---------------
>> Data is stored in form of Documents (BSON).
>> Ex: MariaDB, MongoDB...
